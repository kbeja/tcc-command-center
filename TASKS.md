## OPT-010 Extract useSupabaseQuery generic hook to eliminate boilerplate
**Area:** Optimization · **Severity:** Duplication · **Status:** open
**File:** `src/lib/hooks.js`
**Description:** The fetch-loading-useEffect pattern is repeated 14+ times, ~200 lines of identical boilerplate.
**Fix:** Add a generic hook to `hooks.js`:
```js
function useSupabaseQuery(queryFn, deps = []) {
  const [data, setData] = useState([]);
  const [loading, setLoading] = useState(true);
  const fetch = useCallback(async () => {
    const { data: rows } = await queryFn();
    if (rows) setData(rows);
    setLoading(false);
  }, deps);
  useEffect(() => { fetch(); }, [fetch]);
  return { data, loading, refetch: fetch };
}
```
Refactor each specific hook to use it.
